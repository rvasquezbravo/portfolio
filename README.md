# Rafael Vasquez Portfolio — GitHub Pages

This is the static version of the portfolio. It does not require Node.js or a build process.

## Open locally

Double-click `index.html`.

## Publish with GitHub Pages

1. Upload every file in this folder to the root of the GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder, then save.

GitHub will provide the public URL after deployment finishes.

## Main files

- `index.html`: website entry point.
- `styles.css`: desktop and mobile design.
- `rafael-san-francisco.jpg`: portrait image.
